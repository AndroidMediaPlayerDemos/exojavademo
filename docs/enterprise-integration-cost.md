# 企业源集成成本与限制清单（T4.4）

> 任务：TASKS.md M4 / T4.4 · 对应 PRD FR-7 验收产出物
> 日期：2026-11-08 · 依据：`docs/enterprise-source-research.md`（T4.1 官方事实核对）+ T4.2/T4.3 落地实现
> 路线基线：**A：SharePoint 静态文件 + Cookie 注入直连**（AMS 已退役出局）

## 1. 权限模型

| 项 | 结论 |
|---|---|
| 权限体系 | 复用 SharePoint 原生：站点 / 文档库 / 列表项三级权限（用户、组、分享链接），视频文件即普通列表项，**无视频专用 ACL，无需额外建模** |
| 授权操作 | IT 在 SharePoint 侧为用户/组授予站点或库权限即可，播放端零配置 |
| 拒绝行为 | 无权限账号请求直连 URL 得到 401/403，客户端已给出明确提示（T4.3） |
| 管理成本 | 无新增管理面；审计走 SharePoint 原生访问记录 |

## 2. 鉴权与凭据生命周期

| 项 | 结论 |
|---|---|
| 登录方式 | App 内 WebView 交互式登录（Entra ID，可能含 MFA），每用户每会话一次 |
| 凭据形态 | `FedAuth`（会话 Cookie）+ `rtFa`（刷新 Cookie，临近过期静默续期）；注入 JVM `CookieHandler` 后由 HttpURLConnection 全程自动携带（T4.2） |
| 有效期 | FedAuth 默认约 **10 小时**；租户启用条件访问会话控制可压缩到约 **1 小时**；实际值因租户策略而异（待实测项①） |
| 过期处置 | 播放报 401/403 → 客户端提示「重新登录」→ WebView 刷新 Cookie → 重试自动重注入（T4.2/T4.3 已打通） |
| 安全红线 | Cookie 只在存储间搬运，不进界面、不进日志、不硬编码（已实现，随代码评审与 CI 保障） |
| 备选鉴权 | A2：MSAL Bearer 调 Graph `/drive/items/{id}/content` 换预认证短时 URL —— 需注册 Entra 应用 + `Files.Read` 等权限申请 + MSAL 依赖，主路线受阻时再启用 |

## 3. 格式与播放能力

| 项 | 结论 |
|---|---|
| 传输形态 | 渐进式文件直连（HTTP(S) + Range），支持 seek；非流媒体协议 |
| 自适应码率 | **无 ABR / 多码率**。弱网自适应是硬需求时启用演进路线 B：Blob 离线打包 HLS/DASH + Azure CDN（微软官方 AMS 迁移工具即此形态），需新增打包流水线与 CDN 成本 |
| 格式支持 | 浏览器可播放的格式（MP4/H.264 等设备支持范围内的容器与编码） |
| 单文件上限 | SharePoint Online **250 GB**（官方服务描述），远超视频场景需求 |
| URL 形态 | 库内路径直连与 `/:u:/` 分享链两种形态的 Range 兼容性待实测（待实测项②） |

## 4. 缓存策略

| 项 | 结论 |
|---|---|
| 现状 | PoC 无本地缓存：每次播放全量网络拉流（ExoPlayer 默认不缓存），重复观看重复消耗带宽 |
| 可选演进 | Media3 `SimpleCache`（注意与 Cookie 鉴权源的配合需缓存键不含凭据）；离线下载属产品化议题 |
| 服务端 | 无自有服务端；SharePoint 即静态托管，CDN 前置属路线 B |

## 5. 网络与租户依赖

| 项 | 结论 |
|---|---|
| 连通性 | 客户端须可达 `tenant.sharepoint.com`（公网或企业网络/VPN） |
| 条件访问 / Intune | 租户策略可能约束 WebView 登录（MFA、设备合规）；影响程度待实测（待实测项③） |
| 拉流限流 | 非交互式连续 Range 拉流的限流阈值**未文档化**；长视频（>30 min）是否触发 429/中断待实测（待实测项④） |
| 全量凭据域 | 仅 `*.sharepoint.com` 精确主机匹配注入（实现层已限制，不跨租户泄漏） |

## 6. 成本汇总

| 维度 | 增量成本 |
|---|---|
| 云服务 / 费用 | **零**：复用现有 M365 / SharePoint，无新增托管服务（AMS 退役后亦无第一方可买） |
| 客户端开发 | 已投入：FR-10 认证页（M1）、T4.2 凭据链路、T4.3 失败路径；后续仅维护 |
| 运维 | SharePoint 原生权限管理，无新增运维面 |
| 升级到 ABR（路线 B） | 打包流水线（ffmpeg/Shaka Packager）+ Blob 存储 + CDN 流量费，按需启用 |
| 升级到 A2（Graph 鉴权） | Entra 应用注册与权限审批 + MSAL 依赖，按需启用 |

## 7. 待实测项（并入真机验收 T1.1 / M4 验收）

1. FedAuth 实际有效期（本租户策略下的真实值）
2. 两种 URL 形态（库内路径 / `/:u:/` 分享链）的 Range 兼容
3. 条件访问 / MFA / Intune 对 WebView 登录的影响
4. 长视频连续拉流是否触发未文档化限流（429 / 中断）

---

**结论**：路线 A 的集成成本结构为「零服务端成本 + 一次性客户端开发（已完成）+ SharePoint 原生权限运维」；主要限制是无 ABR、Cookie 会话生命周期、以及四项待实测的租户相关行为。满足 Demo / 内部培训视频 PoC 的验收目标；产品化前再按需评估路线 B（ABR）与 A2（免 WebView 鉴权）。
